# 页面构成：让信息关系决定版式

页面不是容器集合。先识别信息之间的关系，再决定如何排版。

## 常用页面语法

- **论点 + 证据**：上方为完整主张，主体使用一张核心图表、数据表或一组相互支持的证据，必要时加入解释与限制。避免把证据拆成多个等权卡片。
- **双对象比较**：两侧共享同一组维度、基线和单位。维度超过三项时优先表格而非两张大卡。
- **高密度台账**：使用表格或分组行，保留负责人、状态、时间、金额、依赖和下一步；用排序和轻量强调体现优先级。
- **数量关系**：用条形、柱形、折线、瀑布或堆叠直接表达总额、构成、变化和差异。数据不足时使用计算式和明细表，不画装饰图。
- **时间与阶段**：使用时间轴或分阶段泳道，显示日期、责任、依赖和完成标准；不要仅排列编号方块。
- **流程与因果**：方向唯一，连接线表达真实关系。并列事项没有流程关系时，不强画箭头。
- **原始证据**：截图、原文或照片应足够大，配合局部标注、简短结论和图注，不缩成装饰图片。
- **聚焦页**：一个结论、决定或关键数字成为视觉中心，并保留必要的单位、时间、口径或解释。
- **章节与封面**：只承担导航和主题切换，避免无意义副标题、装饰英文和生成日期。

## 构图规则

1. 建立标题 → 主要证据 → 解释/结论的主阅读路径。
2. 同级元素严格对齐；非同级元素通过字号、留白、线条和位置区分。
3. 内容块宽度由文字长度和比较需求决定，不默认等宽。
4. 留白用于分组和强调，不以覆盖率作为机械指标。页面看似空时，先判断是否是合格聚焦页；若不是，检查信息是否被过度压缩或版式是否选错。
5. 避免孤立短行、随意断句和过窄标题框。中文标题默认使用完整安全宽度并自然换行。
6. 同一页只设一个主强调色；颜色编码全篇保持同义。
7. 表格和图表注释靠近对象；页面级来源可进附录，不能牺牲可追溯性。

## 密度判断

- 低密度：一个主张或关键数字，使用聚焦构成。
- 中密度：一个主张加2—4组证据，使用主次分栏、比较、流程或图表加解释。
- 高密度：多行明细、多维比较或复杂口径，使用表格、分组、局部放大和附录，不转成卡片墙。

优秀页面可以很密，也可以很空；关键是信息层级清晰、证据充分且没有视觉噪声。
