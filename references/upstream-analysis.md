# 原 Skill 分析与改造取舍

分析对象：`op7418/guizang-ppt-skill`，线上 `main` 分支提交 `c91369c`（读取日期：2026年9月1日）。

## 值得保留

1. **单文件交付**：HTML 包含样式、交互与演示运行时，降低打开和分享门槛。
2. **渐进式说明**：入口只负责路由，主题、布局、截图、配图和校验拆到 references，避免一次加载所有规则。
3. **内容匹配版式**：先判断数据类型和叙事目的，再选登记版式，能减少“先选好看的模板再硬塞内容”。
4. **真实运行约束**：键盘、滚轮、触屏、索引、低功耗、离线降级和演讲者模式均被当作产品能力，而非装饰。
5. **图片槽位契约**：先确定比例和版式，再生成或适配图片，避免截图和图片把页面撑破。
6. **校验与视觉复核并行**：静态脚本检查结构，浏览器视觉检查处理溢出、留白和可读性，两者互补。
7. **明确反模式**：把真实踩坑写成检查项，例如占位符残留、字体不可读、类名缺失、导航遮挡和伪图表。

## 不直接照搬

- 原 Skill 的视觉语言强、规则量大，容易让模型为了符合风格而压缩内容或过度装饰。
- 瑞士风包含专属版式锁、字体阶梯、IKB主题、WebGL/ASCII和专用校验器，与管理咨询演示目标不同，已从改造版路由和资源中移除。
- “麦肯锡风”不能只替换颜色；必须重写叙事逻辑、行动标题、证据表达、图表规则和版式登记。

## 改造结果

- 最终版本只开放麦肯锡式管理咨询风格，电子杂志与瑞士风资源不参与路由。
- 用麦肯锡式管理咨询视觉系统统一封面、正文、数据页与结尾页。
- 新增金字塔、MECE、SCQA、行动标题、So what 和管理层决策页规则。
- 新增 C01—C11 版式登记、干净模板和专用校验器。
- 不宣称复制麦肯锡官方品牌或内部模板，只采用通用管理咨询表达原则。
