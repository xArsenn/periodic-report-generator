# 发布、交互与隐私边界

## 两种交付

- 内部阅读版：可包含授权的原文对照、源截图与信息映射，保持离线单文件。截图点击或 Enter/Space 放大，Esc 关闭并恢复焦点。
- 对外展示版：不包含完整原文、内部映射、制作诊断、文件路径、账户截图、账号或税号；检查隐藏弹窗、HTML 注释、脚本和图片。需要解释操作时可用事实支持的功能流程替代截图，不能伪造软件界面。
- 对外版仍可能包含商业信息；去掉原文不是完成保密审查。交付给用户本地审核，不自动发布到公共网站或仓库。
- 原材料中的业务问题不能当作“编辑提示”删除。受众理解数字必须知道的单位、期间、范围与状态保留。

## 交互与排版

默认模板提供：键盘、滚轮、触屏、目录、图片放大、全屏入口、演示控制自动隐藏、打印样式及减少动态偏好。
演示模式空闲约 2.4 秒隐藏导航；移动鼠标或键盘操作恢复；键盘焦点进入导航时保持可见。
图片放大时阻止背景翻页，Esc 只关闭图片。全屏受浏览器权限限制，失败写入控制台。
每个对比区域有明显标题、共同基线及分隔；金额列右对齐；流程箭头位于上一步文本块中心。

## 公共仓库

只提交通用 SKILL、参考规则、模板、脚本和明确虚构的示例。禁止提交真实报告、DOCX、原始截图、原文台账、个人路径、密钥和认证数据。
采用明确文件清单暂存；查看 diff 和远程地址；不用 force push。推送后比较本地与远端提交 ID。

## 验收

1. 信息台账逐项核对；检查总额、单位、期间及标题依据。
2. 运行 `node scripts/validate-professional-deck.mjs <file.html>`；这只是结构检查。
3. 实际检查 1366×768、1920×1080、超宽视口，以及全部交互和打印分页。
4. PDF 需实际导出后检查页数、裁切、配色和末页 THANKS，打印 CSS 不等于 PDF 已验收。
5. 环境阻止浏览器或 PDF 检查时，不绕过限制；明确哪些项目尚未验证。
