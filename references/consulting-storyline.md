# 专业演示叙事结构

专业咨询方法只用于提高表达清晰度，不代表每份演示都是经营汇报，也不声称复制任何公司的专有模板、品牌或内部材料。

## 先选择叙事模式

- 决策型：适合方案、经营分析、复盘和管理沟通。采用结论先行、证据、取舍和行动请求。
- 解释型：适合教学、概念说明、流程讲解。采用问题 → 原理 → 示例 → 应用 → 总结。
- 展示型：适合产品、项目成果、作品集和发布。采用价值主张 → 核心能力 → 场景/证据 → 差异 → 下一步。
- 故事型：适合主题分享、案例演讲和观点表达。采用钩子 → 背景 → 冲突/问题 → 转折 → 结论。

不要给所有模式强行增加执行摘要、风险表或管理层请求。结构必须服务展示目的。

## 核心原则

- 信息先行：决策型先给结论；解释型先给问题和认知地图；展示型先给价值；故事型先给钩子。
- 金字塔结构：先写总答案，再拆成 3—5 个支撑论点。无法支撑上层结论的页面应删除、合并或移入附录。
- MECE：并列论点尽量不重叠且覆盖当前问题；不要为了凑三点强行拆分。
- SCQA：用 Situation—Complication—Question—Answer 组织叙事，但不必把四个英文词写在页面上。

## 页面写法

决策型页面按以下顺序思考：

1. 行动标题：完整句子，直接表达本页结论。
2. 证据：数字、事实、访谈、流程或来源。
3. 洞察：证据意味着什么。
4. So what：对决策、资源、风险或行动的影响。

解释型或展示型页面可以使用“它如何工作”“三个核心能力”等准确主题标题，但标题必须帮助观众预测本页内容，不能只是“其他”“内容介绍”。

## 推荐顺序

根据所选模式组织页面，不为空结构强行加页。周报/月报结构只有在用户材料和目的确实属于周期报告时才使用。
