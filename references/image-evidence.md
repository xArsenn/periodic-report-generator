# 图片证据与单文件嵌入

## 图片角色

- 截图、票据、系统界面：保真优先，使用 `contain`，不得裁字。
- 照片、人物、场景：叙事优先，可用 `cover`，但需检查主体安全区。
- 信息图：文字语言与演示一致，图中不重复页眉、标题、页码或来源。

## 处理流程

1. 明确图片支持的结论和最终槽位比例。
2. 检查敏感信息，必要时先脱敏。
3. 同组图片统一比例、容器、边框和图注密度。
4. 本地开发时使用相对路径；交付单文件前运行：

```powershell
node scripts/embed-local-images.mjs path/to/index.html --out path/to/index-single.html
```

脚本只嵌入本地 `img src`，不会下载远程图片。远程资源应先经用户授权保存到本地。

## C14要求

图片、图注、证据含义和来源必须同屏。图片只是素材，读者必须能从文字中知道应该观察什么。
