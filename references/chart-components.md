# 专业图表组件

图表必须服务一个明确比较关系。默认使用原生HTML/CSS或内联SVG，确保离线、可打印、可嵌入单文件。

## 组件选择

- 排序与差异：水平条形图。标签左、数值右，只高亮关键系列。
- 时间趋势：折线图。最多3条线，坐标、单位和时间范围完整。
- 差异桥接：瀑布图。用于预算到实际、上期到本期的增减因素。
- 进度：单条进度条或里程碑，不用仪表盘。
- 构成：优先100%堆叠条形图；只有单时点、2—5个部分时才考虑圆环图。
- 单一关键数字：C15 Data Hero，不画没有意义的图表。

## 统一规则

- 图表标题写结论，不写“收入趋势图”。
- 坐标轴从合理基线开始；截断轴必须明确标识。
- 数据标签不互相遮挡；小屏无法阅读时减少标签而不是缩小到13px以下。
- 颜色保持主色、灰色和最多一种语义色。
- 图表旁必须有So what，说明对决策的影响。
