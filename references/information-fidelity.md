# 信息保真与可追溯改写

专业展示首先要忠实呈现材料，其次才是提炼和美化。重组不等于改写事实，简洁不等于删除条件。

## 信息台账

生成页面前建立内部台账：

`信息ID → 原文事实/数字 → 主体 → 时间范围 → 单位 → 状态或限定语 → 来源位置 → 目标页 → 呈现方式`

原文中的数字、主体、时间、因果、状态、依赖、问题、预算构成、下一步和“不确定/待确认”等限定语均视为独立信息单元。相同内容可以合并，不能无记录地删除。

## 改写边界

- 可做：去除重复、纠正明显错别字、合并同义表达、调整顺序、把长句拆为表格或图示、统一单位和标点。
- 谨慎做：把事实概括成结论。结论必须能由同页证据直接支持，并明确标为“判断、建议、推断”之一。
- 禁止做：替换原意、提高确定性、补写原文没有的原因或影响、把计划写成成果、把局部数据扩大为完整周期、为了页面简洁删除关键门槛或限定条件。
- 原材料存在矛盾、疑似错误或口径不清时，保留原值，在制作控制台输出核对记录，不能擅自选择一个版本或在展示页插入编辑提示。原文自身的风险、条件、未完成状态仍保留在正文；不能把尚未核验的方案包装为权威结论。

## 信息保留优先级

1. 决策所需数字、门槛、时间和单位。
2. 口径、数据来源、适用范围、前置条件和待确认事项。
3. 已完成、进行中、计划中、风险等状态差异。
4. 费用构成、路径差异、依赖关系与行动清单。
5. 背景和过程描述。

页面放不下时先拆页，不先删减1—4级信息。只有重复或无法支持展示目的的5级信息可以优先压缩。

## 页面可追溯

- 每个正文页在HTML中使用 `data-source-refs` 记录所承载的信息ID或原文段落号；该属性不显示给观众。
- 完成后反向核对台账：每个1—4级信息必须已展示、明确移入附录，或记录合理的排除原因。
- 视觉标题可以提炼，但页面正文必须能还原标题所依据的原始事实。

## 参考成品的使用

参考HTML、PPT或截图只用于提取布局原则、信息层级、数据表达和阅读节奏。不得复制其品牌、装饰、固定文案或与当前材料不匹配的结构。先说明参考样本为什么有效，再把原则转译为当前演示自己的视觉系统。
