# 专业展示方法

本方法用于把材料编辑成可理解、可核查、可行动的展示，而不是把文字简单切页。

## 1. 判断任务，而不是套故事

先回答四个问题：受众具备什么背景；他们是现场听讲还是独立阅读；他们需要理解、比较、判断、批准还是记住什么；原材料能支持事实陈述、分析判断还是明确建议。只有在任务确实需要决策时，才使用“结论—依据—行动”。

## 2. 三层信息架构

- **展示层**：标题链与关键视觉，使读者快速掌握主线。
- **证据层**：数据、表格、图表、流程、截图和原文要点，证明页面主张。
- **核查层**：口径、来源、限制、待确认项和详细台账，放在同页适当位置或附录。

三层均来自同一信息台账。视觉简化只能改变展示层，不能让证据层或核查层消失。

## 3. 标题链

先写标题，再做页面。把全部正文页标题连续排列并检查：是否形成完整主线；是否存在重复、跳步、无证据结论或矛盾；每个标题是否由本页证据直接支持。行动标题适合分析和决策页；主题标题适合目录、定义、原始记录和没有可靠结论的页面。

## 4. 信息保留与综合

- 合并重复表述，但保留每个独立数字、口径、期限和限制。
- 先用分组、层级、排序、对齐和注释提高可读性，再考虑删减。
- 主线之外但具有审计或决策价值的信息进入附录。
- 对矛盾、异常或疑似错误保留原值，将制作核验记录输出控制台，不擅自修正，也不放入观众页面；原材料中的业务风险与限定条件继续保留。

## 5. 展示结构选择

- **决策型**：问题/机会 → 关键依据 → 选项或建议 → 风险与行动。
- **分析型**：范围与口径 → 发现 → 驱动因素 → 含义 → 后续验证。
- **进展型**：目标 → 已完成 → 未完成/障碍 → 责任与时间。
- **说明型**：对象 → 构成 → 运作方式 → 示例/证据 → 总结。
- **作品/产品型**：价值主张 → 使用场景 → 能力 → 证据 → 下一步。

结构根据材料调整，不规定固定页数或必须出现“执行摘要”。

## 6. 研究依据

- IBCS SUCCESS强调传达信息、组织结构、选择适当图表、简化、提高有效信息密度、校验视觉真实性和统一语义：https://www.ibcs.com/standards/
- IBCS指出表格适合查找高密度数据，图表适合揭示关系；图表与支持的信息应靠近：https://www.ibcs.com/standards/page/4/
- Assertion–Evidence方法强调用完整主张而非主题词作标题，并以视觉证据支持主张：https://www.assertion-evidence.com/
- Nielsen Norman Group强调用位置和长度等易感知属性降低理解成本，复杂图形不应只因能压缩数据而使用：https://www.nngroup.com/articles/dashboards-preattentive/

这些原则用于指导决策，不要求复制任何机构的视觉品牌。
