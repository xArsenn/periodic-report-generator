# 内容清晰度与页面节奏

## 从材料到页面

先把原始材料分为事实、数字、进展、问题、原因、风险、计划和决策请求。聊天记录、日报或文档中的重复表达先合并；“收到”“已知悉”等无业务信息内容不进入演示。

每页只回答一个问题。先写一句读者看完必须记住的话，再选择支持它的证据。若一句标题需要“以及”“同时”“另外”连接多个结论，通常应拆页。

## 页面计划

写 HTML 前建立以下映射：

`页码 → 页面目的 → 行动标题 → 关键证据 → 版式 ID → 图片槽位 → 来源`

页面顺序要形成阅读节奏：封面 → 摘要 → 事实/指标 → 解释/对比 → 行动/风险 → 收束。8页以上至少穿插三种证据形态，如数字、表格、流程、图表或图片，避免连续三页都是卡片墙。

不要重复命名同一层级。页眉、眉题、主标题三者必须各司其职：页眉说明章节，主标题表达结论；眉题只有在补充新信息时才保留。中英文同义标签不同时出现。

## 标题换行

- 正文页标题默认使用完整内容安全宽度，不人为设置明显偏窄的 `max-width`。
- 不在标题中手工插入 `<br>`，也不为了追求两行效果提前换行；让浏览器在文字触及右侧安全边界后自然换行。
- 只有封面、章节幕或收束页为了明确的语义分层，才允许人工断行；断行位置必须对应自然语义停顿。
- 若标题在1920×1080下仍过早换行，先检查文本框宽度、右侧空容器和内边距，而不是缩小字号。

## 信息密度

- 一个页面通常只保留1个结论、2—4个证据模块。
- 一段正文尽量不超过70个汉字；卡片说明通常不超过45个汉字。
- 列表每组3—6项；超过6项时按主题拆分或转为附录。
- 表格通常不超过7行、5列；重点单元格才使用强调色。
- 正文不低于17px，卡片与图注不低于15px。
- 内容放不下时，依次选择：删重复 → 改写 → 换版式 → 拆页。最后才微调间距，不降低字号下限。
- 正文主体通常覆盖内容安全区约60%—85%的高度。若全部信息挤在上半部，应放大关键数字、改成纵向流程/对比、增加证据图或重新分配模块，而不是保留大片无意义空白。
- “有留白”不等于“下半页空置”。留白应围绕信息形成秩序，不能让页面重心明显上浮或偏向一侧。

## 页面占用率与视觉重心

写页前把安全区划分为标题区、主体区和收束区。主体结构应在垂直方向形成完整构图，不能只在标题下排一行矮卡片后让下半页空置。

- 主体不足页面高度的60%时，优先改变信息形态：横向四卡改为纵向流程、2×2矩阵、中心主线、关键数字加解释带，或增加一条真正有信息增量的“因此/下一步”收束带。
- 不通过无意义加高空卡片、放大内边距或添加装饰图形填空。扩大后的区域必须承载关系、解释、证据或结论。
- 横向流程在16:9页面中最多使用三至四步。四步内容较短时，采用上下两层结构：上层说明阶段，下层呈现贯穿全流程的输入、输出或业务价值。
- 每页完成后检查视觉重心：主体包围盒中心应大致落在页面安全区垂直中心附近；若明显偏上，必须重排或改版式。
- 专业布局依靠对齐、比例、层级和信息关系，而不是卡片数量。模块高度、列宽、间距和基线必须统一。

## 图片角色

- 证据截图、票据、系统界面：保真优先，使用 `object-fit: contain`，不得裁掉文字和数据。
- 照片、人物或场景：叙事优先，可使用 `cover`，但要设置主体安全区。
- 图表或信息图：必须与本页结论直接相关；不得把装饰图当证据。
- 同组图片统一比例、高度、边框和图注密度。单张主图优先16:9或16:10，多图统一4:3或16:10。
- 图片内部不要重复整页标题、页码、页眉或装饰边框。

## 可读性优先级

出现拥挤时先测量问题：标题是否过长、模块是否过多、图片比例是否错误、底部是否进入导航安全区。不要用随意增加负边距、缩到小字或叠加浮层来掩盖结构问题。
